БУРМАЛДЭНС — портативная версия БЕЗ npm
========================================

Никаких npm install. Только Node.js.

ДОМА (один раз):
1. Убедись, что установлен Node.js (https://nodejs.org)
2. В папке выполни:
   node init-db.js
3. Запусти:
   node server.js
4. Открой http://localhost:3000
   Вход: R123456 / 1234
5. Скопируй ВСЮ папку на флешку

В КОЛЛЕДЖЕ:
- Если есть Node.js → start.bat или node server.js
- Если нет Node.js → положи портативный Node.js
  (node-vXX-win-x64.zip с nodejs.org) в папку nodejs\
  и запускай start.bat

База данных: файл data/db.json
Технологии: Node.js (встроенный http) + JSON-хранилище
